# Paladin: optional artist-owned runtime PNG exports. No artwork is supplied.
# Each uncommented row: id relative_path width height pivotX pivotY elevation smooth
# Sizes/elevation are logical tiles, NOT source pixels. Paths have no spaces.
# smooth: 0 nearest, 1 linear. Optional trailing columns: frame-count fps
# Animation is a horizontal strip of equal-sized frames. Dimensions describe ONE frame.
# Art is validated against config/art-palette.hex; lighting is unrestricted.
# F6 reloads in game; Debug builds read source exports directly. F7 snaps zoom to 32px/tile multiples.
# Supported IDs: citizen, tree, rock, animal.cow, animal.pig, animal.chicken
# Building modules: house.floor, house.wall, house.roof
# Also: city_keep.floor/wall/roof and bakery.floor/wall/roof
# City object layers/placeholder recipes are configured in config/city-objects.catalog.
# Any ID can be referenced there: e.g. market.stall, stockpile.stack,
# fishing_grounds.station, wheat_farm.crop, pastureland.floor, road.floor.
# Supplying any object art removes that object's entire placeholder geometry.
# Building module width/height specify repeat size; pivot/elevation are ignored
# for these surfaces, whose placement comes from the footprint and wall height.
