# Paladin art files

Keep lasting art work here, organized by pass or subject: generated source images, references, palettes, prompts, export tools, preview screenshots, palette verification reports and catalog backups. Do not save these deliverables in out.

- sunlight-and-shadow: approved palette and direction.
- environment-v8: roof/foundation alignment, wooden fishing platforms, curved roads/coasts, home heating and Logging Grounds notes and previews.
- environment-v7: current water and beach sprites, coast previews, paused animation and zoom continuity notes.
- environment-v6: current modular trees, simplified roofs, broader pixel presentation, shadows and themed night previews.
- environment-v5: current mud facade, grass, generation sources, export tools, verification and previews.
- environment-v4: preceding environment art, sources and previews.
- house-v2 and house-muddy-v3: earlier house previews and catalog backups.
- art-pipeline and renderer-pass: earlier presentation screenshots.

Game-ready sprite exports belong in C:/Paladin/assets/sprites. Build packaging may copy those into out/build; those are disposable runtime copies, not the source artwork.

Reserve C:/Paladin/out for builds, logs and temporary development/test files. When capturing art review screenshots, set PALADIN_SMOKE_SCREENSHOTS directly to the relevant previews folder here, for example C:/Paladin/handoffs/art-direction/environment-v5/previews.
